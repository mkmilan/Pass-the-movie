# Direct R2 uploads (candidate, not enabled in hosted beta)

- The client requests a short-lived, single-key PUT URL after authorization, consent, rate and transactional quota checks. The signature must bind Content-Length, Content-Type and If-None-Match. The browser sends its recorded Blob directly to R2 with no API cookies; it cannot set Content-Length manually.
- Completion checks the object's exact byte length, type and ETag before queueing the existing FFmpeg worker. The worker reads using If-Match and independently validates the media; no client gets permission to read raw videos. An interrupted upload can complete idempotently or expires via the existing 120-second sweep. An upload replay after object deletion may create a late orphan until the signed URL expires; the existing orphan reconciler removes it. Quotas remain conservative.
- Camera capture asks for 720x1280 and 2.5 Mbps, and uses a 720x1280 canvas when the actual camera delivers oversized portrait or landscape frames (where captureStream is supported). Native input beyond 1920 pixels per edge or 2.1 MP remains unsupported. FFmpeg output is still 720x1280 H.264/AAC, 30 fps, three seconds per clip, 15 seconds final, max upload 12 MiB.
- Private beta media gate stays closed. No deployment, provider resource or CORS setting is changed. Local legacy multipart path remains default; opt into local browser direct uploads with NEXT_PUBLIC_PTM_DIRECT_UPLOADS=true and NEXT_PUBLIC_PTM_LOCAL_STORAGE_ORIGIN=http://127.0.0.1:9000, configuring mock CORS as needed.
- Before opening beta, configure private R2 exact app origin CORS for GET/HEAD/PUT with Content-Type and If-None-Match allowed (and Content-Length if requested). Run synthetic real-R2 tests: wrong body size must fail at R2, missing/modified signed headers must fail, conditional overwrites must fail, expiry must fail, correct PUT must complete, incorrect ETag must not process, CORS must work in Android Chrome and iOS Safari, and final playback/download and deletion must work. Local S3Mock does not enforce real signature semantics. Do not loosen the signed length or conditional checks to work around a provider/browser incompatibility.
- Existing hosted worker isolation and legal gates still apply. Measure upload size and encode wall-clock time before deciding on paid capacity.
