# Free pre-production preview

Standalone Next.js UI using the existing camera component and local browser media only. No backend, cloud database, remote uploads or persistent recording storage. Five sequential scenes can be recorded on one phone (or substitute generated sample animations), accepted, passed to the next player, and rendered in a browser MediaRecorder. Download is explicit; native sharing depends on support. Browser export is not the verified server FFmpeg pipeline and may output MP4 or WebM with approximate timing. Cross-device invites, recovery, backend security and real R2/Atlas are intentionally absent. The real application and cloud gates are unchanged.

Run from this directory: npm install, npm run dev. Use HTTPS or localhost for camera access. Chrome is recommended. No paid deployment required. Test with synthetic or consented clips.
